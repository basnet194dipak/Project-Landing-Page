# Project-Landing-Page
A landing page built as part of [The Odin Project curriculum](https://www.theodinproject.com/paths/foundations/courses/foundations) following the [The Odin Project -  Landing Page](https://www.theodinproject.com/lessons/foundations-landing-page)

The project was created to practice the fundamentals of HTML and CSS, with a particular focus on page structure, layout, styling, and Flexbox.

## About the Project

This project recreates a landing page based on the design provided by The Odin Project.

Rather than using a pre-built template or framework, the page was built from scratch using HTML and CSS. The provided design served as the visual reference while the content, images, and theme were customized.

## Features
- Structured multi-section landing page
- Header and navigation links
- Hero section with call-to-action
- Information/content section
- Image-based content cards
- Quote/testimonial section
- Call-to-action section
- Footer
- Custom space-themed imagery

## How to Run

1. Clone the repository:

    ```bash
   git clone https://github.com/basnet194dipak/Project-Landing-Page.git
    ```
2. cd Project-Landing-Page

3. Open `index.html` in a web browser.
No additional dependencies or installation steps are required.


## What I Learned

This project helped me move from writing individual HTML/CSS exercises to building a complete webpage from scratch.

The main focus was understanding how different HTML elements can be structured together and how CSS, especially Flexbox, can be used to control the layout and visual presentation of a page.

It also gave me practice breaking a larger design into smaller sections and building each section step by step.
